# Security

The current web application is the supported version. Historical prototypes are not maintained.

Please do not post credentials, personal financial inputs, or sensitive exploit details in a public issue. Use GitHub's private vulnerability reporting option on this repository when it is enabled. If it is unavailable, open an issue requesting a private reporting channel without including sensitive details.

Include affected version, reproduction steps using fictional data, expected behavior, actual impact, and a minimal proof of concept. Please allow time for investigation and a fix before public disclosure.

Scenario links intentionally contain the user's inputs. Do not treat them as anonymous or confidential. The application should not send those inputs to analytics, advertising, or a scenario-storage service.
